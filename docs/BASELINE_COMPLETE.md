# Baseline実験（p1_cot20）完成記録

**確定日:** 2026-09-20
**モデル:** TransformerLM, d_model=256, n_layers=4, n_heads=4, vocab_size=4000（digit分割BPE）
**パラメータ数:** 約300万

## 最終結果

| 指標 | 値 |
|------|-----|
| Gate 1（CoTデータ品質） | 採用率 100.0% |
| Gate 2（Val Loss） | 初期値から80%超低下、単調改善 |
| sanity_check（学習データへの正答率） | 全カテゴリ 100.0%（50件） |

## 達成した改善（時系列）

1. digit分割トークナイザー導入 → 算数の桁ズレを解消
2. 計算機による事後検算・訂正（`infer.py`） → 掛け算・割り算の誤りを機械的に修正
3. NFKC正規化での表記ゆれ吸収（²/2等）
4. QAテンプレート 8→54件に拡充、連想チェーン構成
5. 質問の言い回しバリエーション（とは/ですか/を教えて/といえば）
6. checkpoint・トークナイザー不一致の自動検出（学習再開時・推論時の両方）
7. character_coverage引き上げ、vocab_size 2000→4000

## 既知の限界（Phase 1として許容し、深追いしない）

- **未知の言い回し・完全に新しいトピックの組み合わせへの汎化はまだ弱い**
  （例:「日本の面積は?」のような未学習トピックに、自信満々で無関係な答えを返すことがある）
- これは300万パラメータ・限定的なテンプレート数という規模の制約によるもので、
  テンプレートを手作業で追加し続けるアプローチでは本質的に解決しない
  （人間の言語表現は無限にバリエーションがあるため）
- **本格的な汎化性能の改善は、Phase 2（10M〜50Mパラメータへのスケールアップ）の課題として先送りする**
  パラメータを増やせば、同じデータ量でも汎化力は自然に向上する見込み
